# unblurt.me

The marketing site. Plain HTML, CSS and a little JS, with no framework and no build step.

**Live:** https://unblurt.me

```
apps/web/
├── index.html        Landing page: hero, scroll story, live demo, showreel, modes, privacy
├── download.html     Per-OS download buttons, setup steps, FAQ
├── privacy.html      Privacy policy (app + website)
├── terms.html        Terms of use
└── assets/
    ├── site.css      All styles and design tokens
    ├── site.js       Story scroll scene, demo + pointer, hero keycaps, edge blur, showreel, OS detection
    ├── product-*.png Product shots (rendered from brand/creatives)
    ├── og.png        Social preview image
    ├── keys.svg      Keycap illustration (generated by brand/illustrations.mjs)
    └── mark.svg      Logo and favicon
```

## Run locally

```bash
npx serve apps/web     # serve handles the clean URLs (/download, /privacy) like Vercel does
```

## URLs

`vercel.json` turns on clean URLs: pages live at `/`, `/download`, `/privacy` and `/terms`, and any `.html` address redirects there (`/index.html` goes to `/`). Link to the clean paths, never to `*.html`.

## Deploy

The Vercel project `unblurt` is connected to this GitHub repo with its root directory set to `apps/web`:

- **Push to `main`** to deploy to production at unblurt.me.
- **Push any other branch** to get a preview URL.

`.vercel/` and `.env.local` are created by `vercel link`. They're git-ignored, so don't commit them.

## Editing notes

- **Download links:** each file link has a `data-asset` pattern; `site.js` points it at the matching file in the latest GitHub Release. Without JS (or if the API is down) they open the latest release page.
- **Imagery:** don't edit `product-*.png` or `og.png` by hand. Change `brand/creatives/` and run `brand/creatives/render.sh`.
- **Story scene:** `#story` is a tall track with a sticky stage. Scroll progress picks one of 7 beats (`data-beat` 0 to 6) and CSS does the rest. Captions live in `.story-caps`.
- **Legal pages:** if the app starts sending data anywhere new (analytics, updates, crash reports), update `privacy.html` in the same change.
- **Copy:** lowercase headlines, short sentences, and no em dashes.
- **Shortcuts:** anything wrapped in `data-mod` shows `⌘` on macOS and `Ctrl` elsewhere.
